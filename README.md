# LeadFlow CRM 🚀

A full-stack CRM (Customer Relationship Management) application built with the MERN stack to manage and track sales leads.

## 🛠️ Tech Stack
- **MongoDB** — Cloud database (Atlas)
- **Express.js** — Backend REST API
- **React.js** — Frontend (Vite)
- **Node.js** — Runtime environment

## ✨ Features
- Add new leads with name, email, phone, company
- Track lead status: New → Contacted → Converted → Lost
- Edit and update lead information
- Delete leads
- Real-time lead count display

### Backend
```bash
cd leadflow-crm
npm install
